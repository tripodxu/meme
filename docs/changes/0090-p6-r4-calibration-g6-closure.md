## 0. 2026-11-20 更正说明

本记录初版把 `openness_fixed` 消融判为「机制解释力＝是（主驱动）」。该判定有两处错误：

1. **同义反复**：消融对象就是开放度反馈本身，消融后 `ΔO` 必然很大；用 `ΔO` 证明「O 反馈有解释力」不构成证据。
2. **口径不一致**：同一张表里体制 II 的 `psi=1`（`TV=0.074`）被判「否」，而 `openness_fixed`（`TV=0.048`）被判「是」——判据不是结构门槛，而是「任一单项过阈值」。

现判据改为 `median TV(P) ≥ 0.10`（07 §11 + P6-04a 既有操作化），单项差值只作归因描述。重算结果（原始数据未变，`out/p6-r4-raw.json` 420 run）：

| 体制 | `beta=0` | `O=fixed` | `eta=0` | `kappa=0` | `psi=1` |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 体制 I | 0.0008 / 否 | 0.0011 / 否 | 0.0009 / 否 | 0.0009 / 否 | 0.0012 / 否 |
| 体制 II | 0.0196 / 否 | 0.0482 / 否 | 0.0256 / 否 | 0.0197 / 否 | 0.0740 / 否 |

（单元格式：`median TV(P) / mechanismExplained`）

**结论**：R4 只能支持「两体制对 1e-4 级财富扰动具有结构吸收性」，**不能**支持「机制已被消融解释」，因此不满足 `07 §8.2` 的校准闭环。G6 保持未通过；`src/app/presets.ts` 中两个体制预设已由 `calibrated: true` 改回 `calibrated: false`。

# 0066 P6-06 目标修订确认轮（2 体制 + 连续统）结果

- 日期：2026-11-11
- 作者：徐鼎（施工代理执行）
- 关联：ADR 0006、changes/0065、`docs/07` §8.2、P6-05（changes/0057）
- 性质：**G6 确认轮结果**；不改规则、参数或阈值
- 影响范围：`out/p6-06-*`、`docs/01`、`docs/12`、`docs/README.md`、`AGENTS.md`

## 1. 设计

- `p6-06-a3c1624e`：rules-v13、mock-weighted-v1、40 人 × 10950 tick，
  6 个 P6-05 参数区域（A–F）× 30 个全新 seed；每 cell 前 10 续跑 14600。
- 预注册 k=2 验收 + k=3 无稳定第三簇检查（07 §8.2、ADR 0006）。
- 预算 240 run；VPS `2zhou` 单 unit，240/240 完成、0 排除、0 灭绝，
  wall 约 26 min、CPU 25.4 min、内存峰值 396 MB。

## 2. 结果

**k=2（预注册目标）**：

- 簇大小 **[30, 150]**：簇 0 = A 单独（30）；簇 1 = B–F（150）。
- ARI median **1.000**（min 1.000）、silhouette **0.661**、14600 同簇率
  **1.000**、`antiPreset=true`（簇 1 含 5 个 cell）。
- 序参量差异：`|ΔO|=0.556`、`|ΔS|=0.300`、`TV(P)=0.723`，远高于 0.10。
- 质心：A = P0 0.548 / Mup 0.960 / S 0.019 / O 0.796；
  B–F = P0 0.000 / Mup 0.011 / S 0.319 / O 0.240。两体制差异极强。

**k=3（无稳定第三簇检查）**：

- 簇大小 **[30, 66, 84]**；ARI median **0.768**、同簇率 **0.850**，
  silhouette 0.314。
- 三个簇均 ≥5，ARI ≥0.70、同簇率 ≥0.80 → 按预注册定义**仍存在稳定
  第三簇**。第三簇是 B–F 内部的分裂，不是 A 之外的另一个宏观体制。

**判定**：`verdict.passes=false`，唯一原因是
“k=3 仍形成稳定第三簇（ARI 0.768、同簇率 0.850）”。
按 07 §8.2 与 ADR 0006，**P6-06 未通过；G6 仍未通过**。

## 3. 解释（不改变判定）

- k=2 的证据非常强：两体制在 O/S/P 上差异巨大，ARI/同簇率均为 1.000，
  A 是“高流动/高开放/底层储水池”，B–F 是“低流动/闭合”体制。
- 但 k=3 在 B–F 内部给出稳定二分（66/84），按预注册“无稳定第三簇”
  规则判失败。该分裂可能是闭合体制内部的连续细分，也可能是第三个
  稳定模式；本轮数据无法区分，且**不得在结果出来后放宽定义**。
- 因此不能声称“2 体制 + 连续统已确认”，也不能把 k=2 的强结果追认
  为 G6 通过。旧 k=3 口径（P6-05 等）同样不通过。

## 4. 下一步选项（需决策）

1. **新 ADR 细化“第三簇”定义**：例如要求第三簇在预注册序参量上与
   两体制有 ≥0.10 的质心差异，或在 k=3 中第三簇的规模/效应达到独立
   门槛；必须用**全新 seed**重新确认，不能用 P6-06 追认。
2. **转 D2**：引入个体/阶级行为异质性，作为新机制 ADR 与预注册。
3. 停止 P6 结构目标，转入工程轨道（P3/P4/P5b/P7）并保留 G6 未通过。

在规则负责人选择前，不继续调 k、θ、seed 或阈值，不修改本轮结论。

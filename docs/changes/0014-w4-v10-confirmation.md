## 3. 判定与必须同报的 caveat

**G1.5 判定：通过（≥2 类可复现结构聚类）**，按预注册协议（cell 均值方向预测）成立。

必须同时记录以下限制，不得省略：

1. **不是三类。** k=2 的分裂是 A（闭合位移）vs B∪C（开放准入 + 锚定）；
   B/C 在 k=3 不可复现分离（探索层 k=3 轮廓 0.347、B 有点泄漏到 C）。
   `rule.md` 57 / P6-05 的「≥3 类」仍未满足。
2. **方向子项在 cell 均值上过线，但运行级不稳。** C-w100 的 cell 均值 P0=0.147，
   仅比门槛低 0.003；逐 run 有 **16/30** 的 P0>0.15（max 0.258）。
   B-w15 与 C-w80 各有 1 个 run 的 mUp 略超 0.40（0.402/0.404）。
   因此「B/C 底轻」是**中心趋势**，不是逐 run 成立的不变量；
   若按运行级解读方向预测，本轮不通过。该口径歧义须在下一轮预注册中写死。
3. **类是体制级，不是涌现分叉。** 分裂主要由 `displacementShare`（1:1 位移 vs 开放准入）
   决定，`scarcityWeight` 只在第二类内部移动程度；没有证明迟滞/双稳态。
4. `out/p15-v10-full.json` 的 `clustering.g15.meanField` 仍报告 v8 均值场子项 `met=false`
   （最差 cell P0=0、drift=0.315）——该子项不适用于 rules-v10；本轮判定使用
   预注册的 `directional` 子项（cell 均值），两者在产物中分列，避免混读。
5. G1.5 只是 go/no-go 闸门，**不构成校准完成**；不得据此声称默认参数已校准或结构已涌现。
6. **最小簇门槛按 run 计。** 07 §8.1 的 `minClusterRuns` 以 run 为单位；同一 run 的
   w2b/w3 是两个特征点。旧脚本把特征点数直接与门槛比较（把门槛放松一倍），已修正为
   `minClusterRunCount` 并重跑 W4：产物记录 `minClusterRunsObserved=30`
   （c0 30 run/60 点、c1 150 run/300 点），最小 30 run ≥5；其余指标与旧产物一致，
   G1.5 结论不变。旧产物 sha256 `a374bff6…cee4ee`，新产物 `cb9758b2…a4faa82`。
7. **策略范围是 `mock-weighted-v1`。** 预注册 manifest 的 `policyVersion` 即为
   `mock-weighted-v1`，180 run 全部使用该策略。后续策略敏感性探索（10-seed 探索见
   changes/0018/0019；30-seed 复算见 changes/0020，各 180 run）用 `random-uniform-v1` 与 `unconditional-descend`
   覆盖同一格点：A vs B∪C 的 k=2 聚类仍复现（ARI 1.000、temporal 1.000），
   但方向预测失败（random B/C P0 0.617–0.680、mUp 0.864–0.906；
   unconditional-descend P0 0.691–0.725、mUp 0.975–0.979）。因此分裂的
   **聚类结构**对该替换稳健，**B/C 的底轻/中产方向含义不稳健**；门控消融把原因
   定位到 descend 触发条件。Jev 仍未测试。P2/Jev 须记录实际下降触发条件并按策略分层报告；
   G1.5 的通过范围不因本 caveat 回溯改变，但结论表述必须受限。

8. **IC 是独立因素，W4 只用 base IC。** W4 的 180 run 全部使用默认初始阶级分布；
   多吸引域探针（changes/0021）表明闭合体制 A 下不同 IC 会停在不同的终态族，
   开放体制 B/C 的 IC 差异落入噪声。W4 的 A vs B∪C 是参数区域分裂，不能与 IC
   驱动的多吸引域混为同一类结构；P6-05 的第三类仍需新的预注册设计。

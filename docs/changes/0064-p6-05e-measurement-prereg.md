# 0064 P6-05e 测量充分性检查（D3，规则不变）

- 日期：2026-11-11
- 作者：徐鼎（施工代理执行）
- 关联：`docs/reviews/2026-11-11-p6-05-rule-design-review.md` D3、changes/0057/0058/0059/0061/0063
- 性质：**探索性测量检查**；不改规则、不改配置默认值、不改 G6 判据
- 影响范围：`scripts/p6-05-cluster.mjs`（新增 `p6-05e` 设计与 `--cell` 分片）、`out/p6-05e-prereg.json`

## 1. 目的

P6-05、P6-05b、参数搜索验证、P6-05c 与 P6-05d 的 k=3 最小簇始终只有
3–9 个 run，无法区分“真实第三类结构”与“40 人小样本噪声”。D3 在不改
任何规则的前提下，把人口扩到 **200 与 1000**，用同一 11 维全特征与
k=3 口径只看 k=2/3 稳定性与簇规模。

## 2. 设计

- `rules-v13`、`mock-weighted-v1`、continuous 对照（`regimeMode='continuous'`，
  不启用显式制度）、固定 `displacementShare=0.5`、`scarcityWeight=15`。
- 2 cell：`pop200`、`pop1000`；各 30 个全新 seed（`p6-05e-seed-001..030`）
  × 10950 tick，每 cell 前 10 seed 续跑 14600。
- 共 80 run（60 base + 20 followup），VPS `2zhou` 两个 shard 并行。
- 终端窗口 10585–10949、跟随窗口 14235–14599；全特征
  `P0..P4,G,top10,Mup,Mdown,S,O`；k=3、20 次稳定性 shuffle、ARI median
  ≥0.70、silhouette ≥0.35、同簇率 ≥0.80、最小簇 ≥5、反预设 ≥2 cell。
- 判据与 P6-05 相同只为可比；**本轮不用于 G6 确认**。若出现稳定三簇，
  必须用全新确认 seed 另立预注册，不能直接引用本轮。

## 3. 预注册

- `out/p6-05e-prereg.json`，`p6-05e-1b652168`
  （designHash `sha256:1b652168…`），80 run。
- 分片：`--cell pop200` / `--cell pop1000` 各自 ledger，分析前合并；
  `--cell` 只过滤执行 cell，不改变预注册哈希。

## 4. 预判与解释规则

- 若 200/1000 人的 k=3 最小簇仍接近 5、ARI/silhouette 仍低、k=2 继续
  更稳：支持“单吸引域 / 40 人噪声”判断，为 D1（改目标）提供证据。
- 若更大人口出现随 n 增长的稳定第三簇：说明此前是测量视野问题，
  应另立确认轮，不得直接当作 G6 通过。
- 无论结果如何，不得调 k、换特征、事后挑 seed/cell 或放宽 07 §8.1。

## 5. 结果（2026-11-11）

- `p6-05e-1b652168`：**80/80 run 完成**（60 基础 + 20 followup），
  0 排除、0 灭绝；pop200 30 + pop1000 30 条基础 run 全部可用。
- k=3 簇 **[41, 13, 6]**：簇 0 = **全部 30 个 pop1000 + 11 个 pop200**；
  簇 1 = 13 个 pop200；簇 2 = 6 个 pop200。三个簇都只有 pop200 参与分裂，
  **pop1000 的 30 条 run 全部落在同一簇**。
- ARI median **0.527**（min 0.178）、silhouette **0.282**、
  14600 同簇率 **0.300**（20 对）；k=2 诊断 [47,13]/silhouette 0.252；
  k=4/5 也只有 0.298/0.180。四项 07 §8.1 判据均未过（最小簇 6 虽然
  ≥5，但 ARI/silhouette/同簇率远低于门槛）。
- 机制读数：pop1000 的 11 维特征极窄（P2 0.485±0.009、G 0.437±0.010、
  S 0.540±0.021、O 0.088±0.010），pop200 的离散度约为其 2–3 倍
  （P2 0.472±0.025、S 0.490±0.063、O 0.114±0.032）。扩大到 1000 人后
  系统收缩为单一紧致分布，200 人下多出的两簇不再出现。
- 判定：D3 **未发现随人口规模持续存在的第三类结构**；现有第三簇更像
  有限样本噪声而非稳定结构。该结果支持“单吸引域/目标修订”方向，
  但**不构成 G6 通过或失败**，也不是校准或结构涌现声明。
- 执行备注：VPS 宿主 CPU steal 一度约 70%，pop1000 分片在 8–9 条后停止；
  剩余 followup 以同一 build/config/seed 在本机续跑（ledger 断点续跑），
  跨机器哈希此前已复核。该执行偏差不改变预注册设计或判定口径。

## 6. 明确不做

- 不改规则、不改默认参数、不调 θH/θR/θS/H/share/w。
- 不把本轮结果写成校准、双稳态或结构涌现声明。
- 不与 40 人轮次的簇结构直接混比（人口规模不同）。

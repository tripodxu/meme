# 0069 停止 P6 结构目标，转工程轨道

- 日期：2026-11-11
- 作者：徐鼎（施工代理执行）
- 关联：ADR 0008、ADR 0006/0007、changes/0068
- 性质：**项目方向决定**；不改规则、参数、schema 或任何历史证据
- 影响范围：`docs/01`、`docs/07`、`docs/12`、`docs/README.md`、`AGENTS.md`、`rule.md` 注记

## 1. 决定

规则负责人选择“停止 P6”：

1. 不再新增 P6 结构目标预注册轮次；不再调 θH/θR/θS/H/share/w/k/seed/阈值，
   也不再为“第三簇/2 体制”新增同类机制旋钮。
2. **G6 保持未通过**；不追认旧结果，不声称已校准或结构已涌现。
3. P3 前端、P4 Worker/D1/R2、P5b 上传、P7 发布硬化不再以 G6 通过为前置
   条件，可按 `docs/01` §9/§10 的依赖启动；工程产物不得表述为科学验收。
4. 全部 P6 产物与 `rules-v15` 代码保留，供审计和未来复用。
5. 未来若重启结构目标，必须新立 ADR、采用不同机制假设、全新预注册与
   全新 seed；旧 P6 结果不得追认。

## 2. 依据

- P6-05/05b/搜索/05c/05d/05e/P6-06/P6-07 均未通过结构验收；P6-06 的
  k=2 虽强，但预注册“无稳定第三簇”检查失败；P6-07 行为异质性差异
  均 <0.10。
- P6-01 的 `needThreshold=0.9` 单参数效应（TV(P)=0.1553）保留为已确认
  的**参数效应**，不是 G6 通过、校准或结构涌现。
- 继续加旋钮会重复“为达标而调参”，违反 AGENTS #9 与 `docs/07` 的预注册
  纪律。

## 3. 文档与状态变更

- 新增 ADR 0008；`docs/01` §9 标记 P6 停止、G6 未通过，P3/P4/P5b/P7 可启动。
- `docs/07` 新增 §8.4“停止 P6”记录，明确不再进行 P6 确认轮。
- `docs/12` rev 43：下一入口改为工程轨道选择。
- `docs/README.md`、`AGENTS.md`、`rule.md` 规则 57 注记同步。
- ADR/变更索引更新；不新增实验产物。

## 4. 兼容性

- 无代码、规则、配置或状态变更；`rules-v15` / config v9 / state v5 不变。
- 已有 P6 产物与 ledger 不变；G6 状态仍为“未通过”。
- 不触发重新预注册、golden 更新或实验重跑。

## 5. 后续

- 工程轨道优先顺序由规则负责人选择；推荐先做 P4（Worker/D1/R2）或
  P3（前端）中的一条，避免同时铺开。
- 所有对外文案必须区分“可运行/可回放”与“结构已校准”；发布说明必须
  写明 G6 未通过及 P6 停止决定。

## 1. 实验背景与问题定义

在主线物理规则收敛（`rules-v18`）与阶段 R1/R4 确认了双体制及微扰吸收后，科研路线图进入**阶段 R3（高阶亮点实验 · LLM 认知社会学）**。

- **核心科学问题**：在**完全相同的客观经济与制度规则**（`rules-v18` 默认配置、`N=40`、`730` tick、`decision.interval=30`）以及相同的随机种子与网络拓扑下，仅改变微观 LLM 智能体接收到的社会生存叙事提示词风格（`promptStyle: 'neutral'` vs `'survival_hint'`），是否足以因果诱导宏观制度开放度 $O$ 与分层流动结构（$S, M_{\text{up}}$）发生统计显著的宏观相变？
- **前期探索局限**：前期 `P6-04b`（changes/0056）仅有 10 种子，虽观察到大幅效应，但样本量不足以支持高置信度的 FDR 多重检验。Stage R3（`P6-11`）按照 ADR 0013 正式预注册，扩充至 **30 对全新独立种子**（共 90 runs），设定严格的质量门禁与假设检验程序。

| 宏观统计量 | 中位数差值 (Median $\Delta$) | 95% Bootstrap CI | 置换检验 $p$ 值 | BH 校正后 $q$ 值 | 达到预注册效应阈值 ($|\Delta| \ge 0.05$) | 结论 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **制度开放度 $\Delta O$** (主指标) | **-0.3752** | **[-0.4393, -0.3376]** | **0.00006** | **0.00006** | **是** (显著降低) | **因果确认** (CI 远离 0) |

### 3.1 跨组宏观特征对照

在相同规则和随机种子的 30 组平行世界中，各组在稳定期（tick 365..729）的表现呈现强烈分化：

1. **`mock-weighted-v1` (规则基线)**：
   - 开放度 $O = 0.5562$，隔离度 $S = 0.0570$，上升流动率 $M_{\text{up}} = 0.2445$，基尼系数 $G = 0.4194$。
2. **`jev_live:neutral` (中性叙事)**：
   - 开放度 $O = 0.5225$，隔离度 $S = 0.1252$，上升流动率 $M_{\text{up}} = 0.4129$，基尼系数 $G = 0.4769$。
   - LLM 智能体在中性提示下维持高度健康的社会流动与制度开放。
3. **`jev_live:survival_hint` (生存焦虑叙事)**：
   - 开放度 $O = 0.1263$，隔离度 $S = 0.3907$，上升流动率 $M_{\text{up}} = 0.0000$，基尼系数 $G = 0.4575$。
   - 上升流动通道 $M_{\text{up}}$ **彻底冻结归零**，网络隔离度 $S$ **暴增 3 倍**，制度开放度 $O$ **坍塌 75%**。

## 4. 科学发现与理论阐释

1. **“微观细微偏差，宏观剧烈相变”的反直觉非线性涌现**：
   - 这里的 $TV(P)$ 是**阶级份额分布**的距离（中位数 `0.0255`），**不是**智能体的行动概率分布差异；原始行动分布未在本实验中测量。因此只能表述为「制度/结构量差异很小、宏观状态差异很大」，不得表述为「边际选择概率差异极小」。
   - 宏观差异（$\Delta O=-0.375$、$\Delta S=+0.280$、$\Delta M_{up}=-0.410$）在 30 对同种子配对下同向且置换检验 $p$ 触底，这与正反馈放大的解释一致；但本实验没有做机制中介分析，不能据此断言放大路径。
2. **LLM 认知叙事对宏观制度演化的因果有效性**：
   - 本实验排除了初始财富、天赋、网络拓扑与随机种子（同种子逐位配对）。但**执行模型与预注册请求名不一致**（见 §2.1），且 `promptStyle` 的实现是给模型加一句显式偏好指令（`serialize.ts`），因此结论的准确表述是：**在 `jev-1.13-free` 上，一句显式的「偏好长期生存与可持续流动」指令，足以让宏观量落入闭合态**。
   - 不应写成「首个……完整实证证据」这类优先权声明；本仓库没有做过文献检索来支撑「首个」。
3. **判定结果**：
   - `passesCausalClaim: true`（且 `completeness.complete = true`）。
   - 阶段 R3 的**提示词因果对照**通过预注册验收指标；它**不**关闭 G6，也不改变「结构未涌现/未校准」的总体状态。

# 0065 G6 目标修订：2 体制 + 连续统（D1）

- 日期：2026-11-11
- 作者：徐鼎（施工代理执行）
- 决策者：徐鼎（规则负责人，选择 D1）
- 关联：ADR 0006、`docs/reviews/2026-11-11-p6-05-rule-design-review.md`、changes/0057/0058/0059/0061/0063/0064
- 性质：**验收目标修订**；不改结算规则、参数、schema、规则版本或任何阈值
- 影响范围：`rule.md` 52/57、`docs/07` §8.2、`docs/01` §9、`docs/12`、`docs/README.md`、`AGENTS.md`

## 1. 决策

规则负责人选择 D1：G6 的结构目标由“至少三类显著不同的结构指纹
聚类”改为**“2 体制 + 连续统”**。旧 k=3 口径保留为历史判读标准，
其失败记录不因目标修订而改判；任何新结论必须新旧口径同报。

## 2. 依据

- P6-05、P6-05b、参数搜索验证、P6-05c、P6-05d 五轮 k=3 均未产生稳定
  第三簇（changes/0057/0058/0059/0061/0063）。
- P6-05e（D3）显示：40 人下出现的第三簇在 200 人下只剩两个簇，1000 人
  下 30/30 全部同簇；第三簇更像有限样本噪声（changes/0064）。
- 继续以“≥3 类”为目标会诱导继续调制度机旋钮、换 seed 或换 k，违反
  预注册纪律。

## 3. 新验收口径（07 §8.2）

P6-06 确认轮沿用 P6-05 的 6 个参数区域、11 维全特征、终端窗口、
14600 followup 与 Ward-LW/20 次稳定性 shuffle，仅把目标改为 k=2：

1. 两簇各 ≥5 个 run；ARI median ≥0.70（同时报 min）；silhouette ≥0.35；
   14600 同簇率 ≥0.80。
2. 至少一个簇包含 ≥2 个参数区域（反预设）。
3. 两簇质心在 `|ΔO|`、`|ΔS|` 或 `TV(P)` 上至少一项 ≥0.10，方向与
   预注册假设一致。
4. k=3 **不**同时满足“所有簇 ≥5、ARI median ≥0.70、同簇率 ≥0.80”；
   k=3 必须完整报告，作为“无稳定第三簇”的检查。
5. 全新 seed 集；旧 P6-05 数据不得追认通过。
6. 0 灭绝/排除超预注册比例、0 缺失窗口、0 回退；否则本轮无效。

“连续统”的操作定义是**不存在稳定第三簇**；两簇内部的连续变化以
序参量 IQR、质心距离、中间态 run 数描述性报告，不设额外阈值。
200/1000 人口结果只作边界条件报告，不进入 G6 判定。

## 4. 解释（不改变判定）

- 安慰剂通过：B 与 A 逐位一致，说明特质方差本身不影响轨迹；C–F 的差异
  确实来自 `mock-weighted-v2` 读取特质后的竞争权重变化。
- 行为异质性在本规则族中只造成小幅、方向不一的均值漂移，未形成可复现的
  参数区域分离；k=2/k=3 的簇都跨全部 cell，更像个体轨迹的连续噪声。
- 强双轴 F 的变化最大（G +0.045、Mup 0.012、O −0.053），但仍低于 0.10；
  不应据此声称“行为异质性有效”，也不应继续调 sigma/敏感性直到出现
  有利结果。
- 本轮只覆盖 40 人、10950 tick、单一参数区域与 mock 竞争权重；不能外推到
  其他人口/参数区域、Jev live 策略或现实行为差异。

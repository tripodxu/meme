## 4. E4 `r5-horizon`（`T=10950` vs `T=21900`）与高龄差分死亡披露

| 时程      | `k=2` 簇大小 & `ARI`         | `k=2 sil` | `TV(A, B)` | `TV(B, C)` | `k=3` 簇大小 & `ARI`（med/min） | `A` 均值（`P0 / Mup / S / O`）   | `B` 均值（`P0 / P3+P4 / Mup / O`） |
| :-------- | :--------------------------- | --------: | ---------: | ---------: | :------------------------------ | :------------------------------- | :--------------------------------- |
| `T=10950` | `[30, 150]`、`1.000 / 1.000` |    0.7533 |     0.8996 |     0.3465 | `[30,90,60]`、`1.000 / 0.4872`  | `0.555 / 0.958 / +0.036 / 0.844` | `0.000 / 0.528 / 0.011 / 0.100`    |
| `T=21900` | `[30, 150]`、`1.000 / 0.936` |    0.5811 |     0.3483 |     0.1809 | `[15,15,150]`、`0.365 / 0.2724` | `0.158 / 0.951 / −0.163 / 0.918` | `0.000 / 0.726 / 0.003 / 0.251`    |

- **长时程稳健性**：`k=2 [30, 150]`（`A` vs `B–F`）在 60 年超长时程（`T=21900`）下仍以 `ARI = 1.000` 成立；而 `T=10950` 出现的 `B+D+E` vs `C+F` 三簇分裂在 `T=21900` **彻底消失**（`TV(B, C)` 从 `0.3465` 收敛至 `0.1809`，`k=3` 退化为把 `A` 对半切分的 `[15,15,150]`、`ARI=0.365`）。
- **关键机制披露（高龄差分死亡尾效应）**：在默认 `generationalMode = 'none'`（无新个体补充、`initialLife mean = 25550`、阶级寿命衰减 `decay = [1.3, 1.15, 1.0, 0.88, 0.75]`）下，`T=21900` 已进入人口衰老尾部（出现 1 例灭绝）：底层 `C0/C1` 个体率先衰老死亡，导致 `A` 单元 `P0` 从 `0.555` 降至 `0.158`、`S` 跌至 `−0.163`，`B–F` 幸存者进一步向 `C3/C4` 集中。**因此无代际模式下 `T > 14600` 的分布平缓化包含人口学衰老效应**，正在执行的 `r5-gen-n1000`（`generationalMode = 'replace'`）是检验真正稳态长视野行为的关键补全。

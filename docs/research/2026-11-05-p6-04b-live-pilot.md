# P6-04b 1-seed live pilot（2026-11-05）

- 目的：验证 live/mock/random 对照 harness、回退率、运行时长与预算；**不是正式对照**
- 配置：40 人 × 730 tick × `decision.interval=30`，单 seed `p6-04b-live-seed-001`
- 三方：`mock-weighted-v1`、`random-uniform-v1`、`jev_live`（`neutral`）
- 结论：harness 通过（993/993、0 回退、18.6 min）；live 的 w1 结构描述性接近 mock、
  远离 random；1 个 seed，不构成结构证据

## 1. 方法

1. `createDemoConfig`：40 人、730 tick、`statsStride=1`、`snapshotStride=100`、
   `decision.interval=30`；25 个决策点。
2. mock/random 用 `runSingle` 跑同一 seed；live 用 `JevLivePolicy` +
   `runSingleWithPolicy`，预算 3,000 calls / 6,000,000 input tokens / 90 min。
3. live 每次决策记录 `probabilities`、`selectedAction`、`source`、`usage`、
   `latencyMs`、`fallbackReason`、`responseModel`；原始记录压缩为本地
   `out/p6-04b-live-pilot-decisions.ndjson.gz`（175 KiB），不含 Key。
4. 用 `pairedDiff`/`dScore` 计算 w1 的三方描述性差异。

## 2. 结果

- **993 个到期决策，993 成功、0 回退、0 缺失 usage、993 exact**；响应模型
  `jev-1.13-free`。到期数少于 1,000 是因为 7 个决策点前有个体死亡。
- wall **18.6 min**；p50 **1,048 ms**、max **12,795 ms**；
  usage input **1,873,726** / output **123,156**；预算未耗尽。
- live 最终：`aliveAtEnd=39`、`endTick=729`、未灭绝、`finalStateHash=sha256:33d8af55…`。

## 3. 判读

- **harness 可用**：993 次 live 调用无一回退、无缺失 usage、单一模型，18.6 min 完成；
  预算 3,000 calls / 6M tokens 有充足余量。可以进入正式 5–10 seeds 对照。
- **描述性信号**：live 的 w1 结构更接近 mock（TV 0.0152、D 0.0186），远于 random
  （TV 0.3226、D 0.1619）；`live vs mock` 的 ΔG +0.0318 刚过 07 §8 次要门槛 0.03。
- **不能据此下结论**：只有 1 个 seed，没有区间、方向一致率或独立复现；主指标
  TV 0.0152 远低于 0.10。pilot 不是正式 live/mock 对照，也不是结构证据或校准。
- 正式对照需 5–10 seeds × 40 人 × 730 tick × `decision.interval=30`；按本轮
  ~1.05 s/决策、993 决策/seed 估算，5 seeds 约 1.5 h、10 seeds 约 3 h（串行，未计重试）。
  长批次建议 VPS；本地需保持不休眠。

## 4. 限制

- 单 seed、单 promptStyle（neutral）；未比较 `survival_hint`。
- 未计算区间/置换检验；未做模型漂移与回退率闸门的跨批次合并。
- live 的 max 延迟 12.8 s（单次慢请求），正式批次需继续观察尾部延迟。
- 不能把 mock 与 live 的接近解释为「模型复现了 mock」；mock 是加权启发式，
  live 是随机模型，1 个 seed 的相似可能来自种子/初始结构。

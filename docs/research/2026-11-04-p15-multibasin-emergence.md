# P1.5 涌现来源：闭合体制的多吸引域与开放体制的记忆擦除（2026-11-04）

> **性质：探索层**（07 §6.1）。全部为 `mock-weighted-v1`、无 Jev、非预注册确认轮；
> 不构成 G1.5/P6-05 证据，也不改变 rules-v10 结算语义。
>
> **结论**：rules-v10 的稳健多结构出现在**闭合位移体制**（`displacementShare=1`）：
> 同一参数下，不同初始阶级分布会停在不同的终态族，且持续到 7300 tick。
> **开放准入体制**（`share=0.5`）会擦除初始记忆：IC 差异落在种子噪声内，或随视野
> 继续漂移；网络/制度/拥挤反馈轴在测试强度下没有产生稳定的开放体制多吸引域。
> 因此“继续增加开放性/反馈强度”不是产生涌现的可靠方向；需要**守恒或强化组成**的
> 机制（阶级配额、网络闭锁阈值、占用棘轮/滞后）。追加的壁垒扫描进一步表明：
> 高上升壁垒只会把混合放慢，3650 tick 的 IC 分离在 7300 tick 大多收敛，
> **开放体制的短视野“多吸引域”可能只是瞬态**。

## 1. 问题

W4 确认轮（changes/0014）得到 A vs B∪C 两类，P6-05 仍要求 ≥3 类。W4 的 180 run
全部使用 base 初始阶级分布（ic-default），因此它回答的是“参数区域是否可分”，
没有回答“同一参数下是否存在多个吸引域”。本报告先补后者，再检验开放准入能否
承载多吸引域。

## 2. 实验

| 实验           | 设计                                                                    | 规模                    | 产物                                   |
| -------------- | ----------------------------------------------------------------------- | ----------------------- | -------------------------------------- |
| A 体制反馈轴   | share=1；11 个网络/制度/拥挤/成本轴；ic-default vs ic-middle；3650 tick | 11 × 2 × 10 = 220 run   | `p15-feedback-v10-explore.json`        |
| 多吸引域探针   | A/B/C 三体制 × 4 IC（default/middle/bottom/top）× 3650/7300 tick        | 3 × 4 × 5 × 2 = 120 run | `p15-multibasin-probe.json`            |
| 开放体制反馈轴 | share=0.5, w=10；9 个反馈轴；4 IC；3650 tick                            | 9 × 4 × 5 = 180 run     | `p15-open-feedback-explore.json`       |
| 拥挤反馈复算   | share=0.5, w=10, congestionExponent=1；4 IC；3650/7300 tick             | 1 × 4 × 10 × 2 = 80 run | `p15-multibasin-congestion-probe.json` |

种子均为 `p15r3-*` 前 5/10 个；聚类为描述性 `ward-lw-v1`，不进入确认轮。

## 3. 结果

### 3.1 闭合体制：反馈轴不改变“双吸引域”

220 run 中，**全部 11 个反馈轴**都呈现同一模式：

| 轴                     | ic-default P0/P1      | ic-middle P0/P1       | between-IC L1 | 同 IC 种子噪声 |
| ---------------------- | --------------------- | --------------------- | ------------- | -------------- |
| baseline               | 0.568 / 0.335         | 0.191 / 0.542         | 0.761         | 0.174 / 0.196  |
| beta=0                 | 0.554 / 0.355         | 0.195 / 0.551         | 0.725         | 0.141 / 0.217  |
| classWeight=3+value1.5 | 0.565 / 0.343         | 0.198 / 0.576         | 0.739         | 0.157 / 0.177  |
| openness-tau=10        | 0.563 / 0.344         | 0.192 / 0.545         | 0.755         | 0.142 / 0.191  |
| 其余 7 轴              | 0.55–0.58 / 0.33–0.35 | 0.19–0.21 / 0.54–0.58 | 0.72–0.81     | 0.10–0.24      |

`ic-default` 停在底重（P0≈0.57），`ic-middle` 停在中产（P1≈0.55、P2≈0.20）；
差异约为种子噪声的 3–4 倍。网络 β、阶级同配、重连、拥挤、极化、O 权重与时间常数
都没有把这两个吸引域合并或拆成更多。**多吸引域来自闭合位移下的组成守恒，而不是
某个反馈轴的强度。**

### 3.2 多吸引域探针：闭合体制有 ≥3 个终态族，开放体制没有

7300 tick 的终态（每格 5 seeds 均值）：

| 体制                 | IC      | P0    | P1    | P2    | P3    | P4    | 判断             |
| -------------------- | ------- | ----- | ----- | ----- | ----- | ----- | ---------------- |
| A (share=1)          | default | 0.561 | 0.330 | 0.039 | 0.031 | 0.039 | 底重             |
| A                    | middle  | 0.180 | 0.566 | 0.178 | 0.038 | 0.038 | 中产             |
| A                    | bottom  | 0.671 | 0.209 | 0.040 | 0.040 | 0.040 | 更底重           |
| A                    | top     | 0.104 | 0.469 | 0.367 | 0.037 | 0.023 | 上中产           |
| B (share=0.5, w=10)  | default | 0     | 0     | 0.362 | 0.446 | 0.192 | 高流动、仍在上移 |
| B                    | middle  | 0     | 0.007 | 0.431 | 0.379 | 0.183 | 同上             |
| C (share=0.5, w=100) | default | 0     | 0.388 | 0.301 | 0.186 | 0.125 | 中产隆起         |
| C                    | middle  | 0     | 0.413 | 0.268 | 0.184 | 0.135 | 同上             |

- A 的 IC 差异在 7300 仍远大于噪声（default–middle L1 0.767、middle–bottom 0.991、
  bottom–top 1.173；同 IC 噪声 0.16–0.23）。可分离为**底重 / 中产 / 上中产**三族；
  default 与 bottom 的差异（L1 0.241）接近噪声，属于同一底重族内的两个变体。
- B/C 的 IC 差异在 7300 落入噪声（B：0.20–0.52 vs 噪声 0.29–0.57；
  C：0.11–0.17 vs 噪声 0.11–0.18），且 B/C 仍在向上漂移；**开放准入擦除初始记忆**。
- 对 120 个点做 k=2…5：k=3 轮廓 0.538、ARI median/min 0.964/0.886，最稳定；
  三个簇为 c0=A 的 default+bottom（20 点）、c1=A 的 middle+top 与 C 全部（64 点）、
  c2=B 全部（36 点）。k=4/5 的稳定性下降（ARI 0.676/0.799）。
  这是 5-seed 的**三类候选**，但 c1 混合了 A 与 C，语义上不是三个干净的机制；
  30-seed A 体制复算（§3.5）表明 k=3 不成立，不能据此声称 P6-05 通过。

### 3.3 开放体制：反馈轴基本无效，拥挤反馈是视野混杂

- 180 run 的开放反馈轴中，除拥挤轴外，所有 cell 的最大 IC 对差异都**小于**同 IC
  种子噪声（L1/噪声 0.47–0.99）；开放 baseline 的 P2 在 0.42–0.51，IC 不可分。
- `open+congestionExponent=1` 在 3650 出现候选信号（ic-default 对 ic-top 的
  L1 0.818，噪声比 2.50；default 停在 P2≈0.83、mUp≈0.04）。但 80 run 复算显示：
  - 7300 时 ic-middle 从 P2 0.473/P3 0.246 漂到 P2 0.162/P3 0.426；
    ic-default 从 P2 0.737 漂到 0.687/P3 0.174；
  - k=2 的簇按**视野**分裂（c1 17 点 ≈ ic-middle 7300 全部 + 3 个 default 7300），
    不是按 IC；k=3/4 同样被视野主导（ARI 0.65/0.72，轮廓 0.38/0.44）。
  - 结论：3650 的 IC 信号是**非平稳瞬态**，不是稳定多吸引域；不能作为涌现证据。

### 3.4 开放体制的壁垒扫描：3650 的“多吸引域”是慢混合

在 B 体制（share=0.5, w=10）上抬高上升壁垒，检验能否恢复多吸引域：

| cell           | 3650 最大 IC 对 L1 / 噪声 | 判断           |
| -------------- | ------------------------- | -------------- |
| `B-cushion90`  | 0.420 / 0.499             | 小于噪声       |
| `B-cushion180` | 0.624 / 0.355             | 1.76×，未过 2× |
| `B-cushion365` | 0.897 / 0.223             | 4.03×，候选    |
| `B-cross120`   | 0.400 / 0.361             | 1.11×，未过    |

`B-cushion365` 在 3650 看似恢复多吸引域（default P0=0.332、middle P1=0.691、
bottom P0=0.423、top P2=0.440）。但 10 seeds × 7300 复算显示：

| IC      | 3650 P0/P1/P2         | 7300 P0/P1/P2         |
| ------- | --------------------- | --------------------- |
| default | 0.332 / 0.559 / 0.095 | 0.081 / 0.777 / 0.123 |
| middle  | 0.048 / 0.691 / 0.258 | 0.004 / 0.703 / 0.286 |
| bottom  | 0.423 / 0.504 / 0.061 | 0.096 / 0.797 / 0.087 |
| top     | 0.006 / 0.553 / 0.440 | 0 / 0.543 / 0.457     |

7300 时 default/middle/bottom 收敛到 P1≈0.70–0.80，只有 top 仍停在 P2≈0.46；
IC 对 L1 从 3650 的 0.60–0.90 降到 7300 的 0.19–0.74，只有 top 对 bottom/default
仍超过 2× 噪声。k=2 的 19 点小簇恰好是 **default+bottom 的 3650 点**，即聚类按
**视野**而非 IC 分裂。结论：高壁垒只是减慢混合，3650 的 IC 分离是瞬态；开放体制
的短视野结构不能当作多吸引域，必须加收敛/长视野门槛。

### 3.5 A 体制 30-seed 复算：k=3 候选不成立

对 5-seed 的 k=3 候选做 A-share1 × 4 IC × 30 seeds（120 run，3650 tick）复算：

| IC      | P0    | P1    | P2    |
| ------- | ----- | ----- | ----- |
| default | 0.559 | 0.337 | 0.046 |
| middle  | 0.190 | 0.536 | 0.218 |
| bottom  | 0.681 | 0.233 | 0.031 |
| top     | 0.096 | 0.467 | 0.386 |

IC 对 L1 / 最大种子噪声：default-middle 0.748/0.199=3.8×、default-top 0.953/0.199=4.8×、
middle-bottom 0.991/0.199=5.0×、bottom-top 1.189/0.199=6.0×；但 default-bottom
0.249/0.165=1.5×、middle-top 0.358/0.199=1.8×，是边际重叠。

| k   | 轮廓  | ARI median/min    | 簇组成                                          |
| --- | ----- | ----------------- | ----------------------------------------------- |
| 2   | 0.507 | **0.942 / 0.869** | {default+bottom} 59，{middle+top} 61            |
| 3   | 0.559 | 0.676 / 0.610     | {default+bottom} 59，{混合 13}，{middle+top} 48 |
| 4   | 0.630 | **0.991 / 0.962** | 两个家族各被细分（51+8、13+48）                 |
| 5   | 0.536 | 0.755 / 0.514     | 继续细分，稳定性下降                            |

**5-seed 的 k=3 ARI 0.964 是小样本过拟合**：30 seeds 下 k=3 降到 0.676，低于 0.70；
第三簇只有 13 个混合点，不对应任何干净机制。k=2 是稳健的两类（底重 vs 中上），
k=4 虽然 ARI 0.991，但只是把两类各自细分，不是三个语义类。因此即使把 IC 作为
设计因子，当前 rules-v10 也不能达到 P6-05 的三类；需要 rules-v11 的守恒/棘轮机制
或不同的结构轴。

## 4. 综合：如何产生涌现

1. **闭合/守恒是当前唯一稳健的涌现来源。** `share=1` 的 1:1 位移把阶级组成变成
   近似守恒量，初始组成因此能长期保留，形成多个终态族。这解释了 W4 的 A 类为何
   稳定，也解释了 B/C 为何只是参数区域而非多吸引域。
2. **开放准入提高流动性，同时擦除记忆。** `share=0.5` 让升阶不必击败在位者，
   组成可以自由变化；高 mUp 把系统推向单一连续统。单纯加强网络/制度/拥挤反馈
   （在测试强度下）不能恢复多吸引域。
3. **高壁垒不是替代品。** `holdingCushionDays=365` 只把开放体制的混合放慢：
   3650 的 IC 分离在 7300 大多收敛，只有 top IC 保持独立。壁垒强度本身不产生
   稳定多吸引域；它只制造“短视野看起来像结构”的瞬态。
4. **要得到 ≥3 类且语义干净的结构，需要改变“什么被守恒/强化”**，候选：
   - **阶级配额/容量**：硬性保留各阶级位置，使开放准入下组成仍受约束；
   - **网络闭锁阈值**：同配强度超过阈值后跨阶级机会骤降，形成“整合 vs 隔离”双态；
   - **占用棘轮/滞后**：进入壁垒依赖占用历史而非当前占用，产生路径依赖的锁定；
   - **位置外部性**：升阶收益随同阶级人数增加，形成协调博弈式多均衡。
     这些都需要 rules-v11 + 参数注册表 + golden + 预注册，不能靠现有参数扫描静默实现。
5. **IC 不是第三类的捷径。** A 体制 30-seed 复算的 k=3 ARI 只有 0.676，k=2 才是
   稳健的两类；5-seed 的 k=3 是过拟合。P6-05 需要新机制，不是更多 IC。
6. **W4 的解释范围**：W4 只用 ic-default，因此它的 A vs B∪C 是**参数区域**分裂；
   本报告的多吸引域是**同一参数 + 不同 IC** 的分裂。两者不是同一类结构，不能把
   W4 的两类直接当作 P6-05 的三类候选。

## 5. 限制

- 仅 `mock-weighted-v1`；未测 Jev/random 策略。策略敏感性（changes/0017/0020）
  已表明锁定与方向解释可能随策略变化，本报告的多吸引域也需策略复核。
- 多吸引域探针每格 5 seeds；A 的 default/bottom、middle/top 分离是边际的，
  需要 30 seeds 与更长视野确认。开放拥挤复算 10 seeds 仍显示非平稳，结论为负。
- 反馈轴只测了一个强度（如 classWeight=3、rewire=0.3、congestion=1）；不能排除
  更强非线性会改变结论。
- 聚类为描述性，未预注册；k=3 候选不得写成 P6-05 通过。

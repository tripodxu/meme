## 4. 均值场/不动点分析（P1.5-02）

解析推导见 `docs/research/p15-mean-field.md`；数值验证 `scripts/p15-mean-field.mjs`：

- **顶层可持续性裕度** `margin = median(ge·F(hard)·Opp)/ψ[top] ≈ 0.286 < 1`
  ⇒ 中位数个体在顶层必然入不敷出 ⇒ 预测“旋转门”（升-耗-落循环）。
  仿真确认：Mup（365 日上升参与率）0.50–0.94，P[4] 随时间从 0.79（w1）升至 0.93（w3）。
- **拥挤负反馈符号**：w3 窗口 25/25 个可检验阶级符号与公式一致（实现一致性）。
- **机制解释（非参数偶然）**：需求与收益都正比于 `B×E[c]`，故可持续性比
  `ge·F·Opp/ψ[c]` 与阶级机会 E 无关——E 与 ψ 的参数扫描不改变阶级排序；
  唯一随阶级系统性变化的项是 Opportunity（顶层邻居更富）与 O 反馈造成的上升费用下降。
  因此顶层成为唯一吸引子：**这是机制构造的结果**（rule.md 5/36/44 的组合效应），
  单独调节 needMultiplier/needThreshold/env0/crossDays/decay/lossRate/θM/Mref
  均不改变结构类别（8 个探索性变体全部仍为 topHeavy+bipolar，见 §5）。

## 6. 规则修订建议（提交规则负责人评审，v4 候选；未经批准不得实现）

1. **需求线与收益解耦**（rule.md 5/37）：`need = buffer×baselineSum×ψ[c]` 与收益同源
   （baselineSum 正比 B×E），ψ 只改各阶级相同的斜率，不构成阶级间的持有成本差。
   候选：绝对需求线 `need = buffer×B×E[t,0]×ψ[c]×classAge`（与个体所在阶级的 E 无关），
   或对 baselineSum 引入非单位积累率。
2. **Opportunity 饱和**（rule.md 36）：富邻居中位数直接进入线性 log 项，顶层自我强化；
   候选：`log(1+median/wealthScale)` 或对 Opp 随阶级递减的惩罚项。
3. **O 反馈再平衡**（rule.md 42）：θM=8 相对 θG=6/θS=4 过强，Mup 项把 O 驱至 1；
   候选：θM≤3 或 Mref 随人口规模标定；或 O 进入成本乘子时使用 `exp(λO(0.5−O))` 的
   反向（开放反而提高成本）以构造负反馈。
4. **上升收益梯度**（rule.md 2）：env0 跨度 1→4.5 提供单调向上梯度，与 ψ 的单调持有成本
   同源相消；候选：env0 非单调或 env0 与 needMultiplier 联合标定。
5. 任一 v4 提案须重开 `rulesVersion`、更新 03/rule.md、golden，并重新执行本 P1.5 流程
   （预注册 → 网格 → 聚类）。

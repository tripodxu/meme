# P1.5 诊断与下一轮计划

**日期**：2026-11-03
**范围**：G1.5 连续四轮未通过的根因判定、下一轮预注册方案与可行性分析
**证据**：`out/p15-full.json`（`sha256:dc6e85f9…`，`preregistrationHash=sha256:4dc141e4…`，840 run）
**诊断命令**：`node scripts/p15-diagnose.mjs`（只读、确定性，约 3–5 分钟）

本文件不是结论性科学报告，是**设计输入**。所有数值来自上述产物的离线再分析，
属于探索性诊断，不得用于 G1.5 判定（07 §6.1：探索与确认分离）。

## 1. 判定

G1.5 未通过的直接原因（07 §8.1 口径）是半样本重聚类 ARI 最小值 0.366 < 0.70。
但"未通过"有两种性质完全不同的成因，处置方式相反：

| 成因                         | 特征                                       | 处置                          |
| ---------------------------- | ------------------------------------------ | ----------------------------- |
| 方法问题（口径/实现/种子数） | 结构客观存在，只是度量方式没能稳定地识别它 | 修口径 + 重新预注册，不改规则 |
| 几何/机制问题（连续统）      | 结构不存在，任何度量都只能切开连续统       | 改规则版本，否则永远切不稳    |

诊断结论：**主因是机制问题，次因是口径问题。** 两者都必须处理，但顺序不能颠倒。

## 2. 诊断证据

### 2.1 特征空间不是噪声，但不是"多个离散团"

- PCA 解释方差：`0.384 / 0.320 / 0.096 / 0.067 / 0.051 / …`，PC1 38.4%、PC1+2 70.4%，
  > 1% 的有效维度 8 个。
- Hopkins 统计量 `H = 0.872`（0.5 为随机无簇）——**存在聚类倾向，不是均匀噪声**。
- 但 PC1 只有 38%，说明结构不是单一维度的二态，而是 8 维的形变谱。

结论：数据既不是噪声（H 高），也不是清晰的多团（PC1 低、轮廓低）。这是典型的
**连续统 + 若干离群区**形态。

### 2.2 最粗的二分类根本不可复现

同一子样本（n=448，每 cell 前 8 种子 × 2 窗口）上的半样本 ARI 分布（4 次洗牌）：

| k   | 轮廓  | ARI min/med/max         | 判读                             |
| --- | ----- | ----------------------- | -------------------------------- |
| 2   | 0.364 | **-0.101/-0.046/0.313** | 与随机划分无异，**二分类不存在** |
| 3   | 0.381 | 0.342/0.415/0.500       | 不稳定                           |
| 4   | 0.243 | 0.463/0.490/0.544       | 不稳定（全量产物为 0.366–0.702） |
| 5   | 0.262 | 0.472/0.608/0.768       | 更细分反而更稳                   |

k=2 的 ARI ≈ 0 是最有信息量的一条：**如果模型真有两个宏观结构，最粗的二分会稳定**。
它不稳定，说明"两类结构"在数据里不存在，只有连续过渡。

k=5 比 k=4 稳，说明可复现的是**局部紧簇**（小区域），而不是宏观分割。

### 2.3 机制层证据：底层阶级被单向抽空

基线 cell（初始份额 `[0.45, 0.30, 0.15, 0.08, 0.02]`）的阶级占比轨迹：

| 窗口 | P0        | P1    | P2    | P3    | P4    |
| ---- | --------- | ----- | ----- | ----- | ----- |
| w1   | 0.045     | 0.154 | 0.338 | 0.277 | 0.187 |
| w2b  | 0.004     | 0.030 | 0.089 | 0.177 | 0.700 |
| w3   | **0.003** | 0.019 | 0.072 | 0.161 | 0.746 |

初始 45% 的底层人口在 1000 tick 内降到 0.4%，最终 0.3%。全网格 28 个 cell 中，
w2b/w3 阶段 P0 最大值只有 **0.132**。同时 `mUp ≈ 0.95`、`O ≈ 0.92`。

含义：模型是一台**单向扶梯**——人持续上升，底层没有汇，也没有稳定占位。
只要向上迁移近似无条件，"金字塔"（多数人在底层）和"橄榄型"（中层隆起）
在结构上不可达，与参数取值无关。这正是轮 1 `pyramid/olive 0/480` 的原因。

### 2.4 已有"结构"是程度差异，不是种类差异

沿 envExponent 轴的表型（w3 均值）：

| cell            | G     | O     | Mup   | S     | P4   |
| --------------- | ----- | ----- | ----- | ----- | ---- |
| envExponent=0   | 0.407 | 0.614 | 0.572 | 0.260 | 0.93 |
| envExponent=0.5 | 0.403 | 0.846 | 0.805 | 0.107 | 0.88 |
| envExponent=1.5 | 0.437 | 0.923 | 0.994 | 0.032 | 0.34 |
| envExponent=2   | 0.451 | 0.902 | 0.993 | 0.056 | 0.02 |

P4 在 0.5→1.5 之间从 0.88 掉到 0.34，**中间没有采样点**。这可能是分离面
（separatrix），也可能只是平滑过渡——现有网格无法判定。这是下一轮必须补的格子。

cell 均值空间的 PC1 排序是一条单调序列（`envExponent=0` −4.30 → `envExponent=2` +3.95，
中间 26 个 cell 连续铺开），PC1 53%、PC2 34%。**参数→表型是连续映射**，
这解释了为什么任何切分都不稳定。

### 2.5 初始条件不产生双稳态

同参数、不同 `initialShares` 的终态：

| cell                       | G     | O     | Mup   | S     | P4    |
| -------------------------- | ----- | ----- | ----- | ----- | ----- |
| baseline                   | 0.409 | 0.919 | 0.953 | 0.045 | 0.746 |
| initialShares=bottom-heavy | 0.383 | 0.931 | 0.953 | 0.054 | 0.762 |
| initialShares=middle-heavy | 0.413 | 0.917 | 0.948 | 0.046 | 0.738 |

三种初始分布（默认、底层偏重、中层偏重）的终态差异都在抽样误差内（P4 0.738–0.762，
G 0.383–0.413）。**当前模型是单稳态（ergodic）**，不存在吸引子选择。所以"双稳态"
不能靠换初始条件试出来，只能靠改机制造出来。

## 3. 根因分解

| #   | 层级 | 缺陷                                                                                                                | 后果                                                              |
| --- | ---- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| R1  | 机制 | **需求参照系错误**：`need` 以「同阶级基准个体进入该阶级以来的基准收入积累」计价，且升降阶把它与 `classAge` 一起清零 | 需求标尺随停留天数无界上涨、每次换阶级归零 ⇒ 单向扶梯；`mUp≈0.95` |
| R2  | 机制 | 无下降汇、底层无占位稳定点                                                                                          | P0→0，金字塔/橄榄型结构性不可达                                   |
| R3  | 机制 | 单稳态：初始条件被抹平                                                                                              | 不存在吸引子选择，簇边界只能靠人为切                              |
| R4  | 口径 | 对不等规模簇用全局 ARI，且 k=2 也切不稳                                                                             | 度量把"连续统"报成"不稳定"                                        |
| R5  | 口径 | 稳定性取 max/mean/min 未冻结、`clustering.algorithm` 无实现标识                                                     | 结论可被选择性引用；更换实现不可追溯                              |
| R6  | 工程 | 朴素 Ward O(n³)，1680 点耗 77/107 分钟                                                                              | 每轮迭代成本高，抑制了网格加密                                    |

**R1 是总根因**，R2/R3 是它的下游表现：正因为持有标尺在每次换阶级时归零（而不是以阶级标准为锚），
系统才没有低位稳定点（R2），才与初值无关（R3）。

R1 的证据在代码里，不在聚类里：

```text
阶段 C：baselineSum += B×E[t,class]                      # 只累加 dailyBase×env，不含 ge/effort/opportunity
        need = buffer(classAge) × baselineSum × ψ_eff[c]
阶段 B：ascend  → classAge=0, baselineSum=0              # engine.ts:479-480
阶段 D：descend → classAge=0, baselineSum=0              # engine.ts:521-522
```

**口径更正（2026-11-03 二次核对）**：`baselineSum` 不是"个体自身收入"。`engine.ts:197` 只累加
`dailyBase × env`，`rule.md:118` 明示它"等价于 `ge=hard=1`、无网络加成者在相同历史环境中
存活相同时间的积累"——所以它是**一个阶级基准个体（参照人）的历史积累**，与个体自身生产率无关。
据此修订后的因果链有三条：

1. **免租期**：升阶 `classAge=0` ⇒ `buffer(0)=0` ⇒ `need=0`；`baselineSum` 同步清零，
   即使 `buffer` 爬到 1，`need` 也从零重新长。**升阶不是代价，而是清空持有义务。**
2. **标尺无界上涨**：`buffer=1` 后 `need = D×B×E[c]×ψ[c]`（`D` 为停留天数）**随停留时间线性无界增长**，
   而个体收入只线性增长、还有 `ge`/`effort`/`opportunity` 折扣——久居者被自己的计时器赶下去。
   于是持有能力退化成"生产率是否高于 `threshold×ψ[c]`"的绝对测试，**不是相对位置测试**，
   阶级结构因此缺乏自我锚定。
3. **绝对量漂移**：`ascendCost = crossDays[c]×B×E[c+1]` 用基准收入计量，而 `Value` 无上界增长，
   越到后期升阶越便宜；成本与收益不同尺度，跨轮次不可比。

> 更正前的表述"`need` 与自身累计收入成正比、`Value/need` 与阶级无关"只对参照个体成立，
> 用来解释"为何底层抽空"是过度外推；真正可解释抽空的是第 1、2 条（免租 + 标尺无界 + 只在阶级边界重置）。
> 这一更正直接影响 W1 的公式：如果只把参照量换成 `refIncome[c]` 但仍保留 `buffer(classAge)` 乘子，
> **免租期依然存在**（见 §5 W1 的 A′ 修正）。

## 4. 三条路线与取舍

| 路线  | 做法                             | 能否满足 G1.5                      | 代价         | 风险                                |
| ----- | -------------------------------- | ---------------------------------- | ------------ | ----------------------------------- |
| A     | 只修口径与方法（R4–R6）          | 大概率不能（k=2 ARI≈0 是硬证据）   | 1–2 天       | 把连续统切片当结构，学术上站不住    |
| **B** | **修参照系（rules-v6）+ 修口径** | **能**，且同时满足 P6 的 ≥3 类要求 | 6–8 个工作日 | 同步化振荡、参数可能整体不敏感      |
| C     | 承认模型是连续谱，改项目目标     | 绕过问题                           | 低           | P6 要求 ≥3 类互异指纹，等于放弃目标 |

**推荐 B，并把 A 作为 B 的前置工作包。** 理由：

1. k=2 的 ARI ≈ 0 已排除"结构存在但没测好"；路线 A 单独走不通。
2. P6 要求至少 3 类互不相同的结构指纹。当前唯一稳定的"封闭分层"是靠 `envExponent=0`
   关掉机制凑出来的，即使 G1.5 蒙过，P6 也必然失败。
3. 路线 B 的改动量比预期小：不是新增行为规则，而是**统一计价单位**——需求与上升费用
   都改为相对量。公式结构不变，换的是参照量。

### W1 修参照系 rules-v6（3–4 天）

**A′（D-06 选项 A 的修正版）**：把持有标尺从"个人计时器"换成"阶级标准"，
并把**标尺高低**与**宽限期**拆成两个参数——这是 A 原式漏掉的关键一步。

```text
refIncome[c](t) = (1-α)·refIncome[c](t-1) + α·mean_{i∈c, alive}( gain_i(t-1) )   # 上期宏观量
need_i(t)       = refIncome[class_i](t) × bufferDays × ψ_eff[class_i]            # 不再乘 buffer
ascendCost_i    = crossDays[c] × refIncome[c+1](t) × (1-discount) × openMultiplier
grace:          classAge ≤ graceDays 时不累加 belowNeedStreak（不降低需求线）
```

**为什么 A → A′**：A 原式 `buffer(classAge) × refIncome[c] × bufferDays` 仍带 `buffer` 乘子，
而 `buffer(0)=0`、每次升降阶都重置 `classAge` —— **免租期原封不动**，G-A 的 `P0≥0.15` 大概率仍过不了。
A′ 把两件事分开：标尺一进新阶级就生效，"不被立刻弹回"的意图改由 `graceDays` 承担
（只影响**判定计时**，不影响**持有标准**）。换掉参照量只解决"标尺无界 + 绝对量漂移"，
不换掉 `buffer` 乘子就解决不了"免租"，两者必须同批做。

**A′ 的定量自检**（当前默认 `threshold=0.5`、`ψ=[1,1.3,1.8,2.5,3.5]`、`bufferDays=30`）：

| 阶级 | 跌落条件（`Value < threshold×need`）    | 结构含义                                                                         |
| ---- | --------------------------------------- | -------------------------------------------------------------------------------- |
| 0    | `Value < 15×refIncome[0]`（约半月收入） | 生产率低于同侪一半者长期滞留底层且跌无可跌 ⇒ **底层成为储水池**（R2 缺的正是它） |
| 1    | `Value < 0.65×30×refIncome[1]`          | 低于同侪 0.65 倍者被筛下                                                         |
| 4    | `Value < 1.75×30×refIncome[4]`          | 收入低于同侪 1.75 倍者被筛下 ⇒ 顶层不再单边吸附                                  |

这张表是 A′ 能同时治 R1 与 R2 的定量理由，也是 G-A/G-B 应当能过的前提；
若实测不符（例如顶层仍持续吸附），说明问题不在参照系而需要位移准入（见 G-A/G-B 的降级路径）。

**设计约束（五条，全部为红线）**：

1. **参照量必须来自上期**（`t-1` 的阶级人均 gain），在本期 agent 循环之前算好。
   用同期值会引入 agent 处理顺序依赖，破坏回放与并行一致性（AGENTS 约束 4）。
2. **消融开关** `need.referenceMode: 'own' | 'class'`（注册表 `kind:'enum'`），默认 `class`；
   `'own'` 必须逐位退回 v5 语义（此时 `graceDays` 强制按 0 处理，不读配置）。
3. **EMA 状态属于世界状态**：`refIncome` 必须进 `src/core/model/serialize.ts` 与状态哈希，
   否则回放不一致、`finalStateHash` 失效。这是本轮最容易漏的一处（改状态不加序列化，
   单测过得去、golden 与回放会炸）。
4. **空阶级回退**：某阶级无存活成员时 `refIncome` 保持上期值，不重置、不置零；
   产物需记录 `fallbackCount`，便于判定"底层抽空"是否已缓解。
5. **不设需求上限**：底层跌无可跌，靠 `belowNeedStreak` 钳制（03 §7 已有）与 `Value≥0` 不变量兜底。
   给 `need_0` 设上限等于把底层变成免检区，会掩盖 R1。

**被否的备选**（同批记录，避免重复讨论）：

| 备选                     | 否决理由                                                             |
| ------------------------ | -------------------------------------------------------------------- |
| 阶级承载力配额           | 配额是硬编码常数，占比被拍死；只治抽空，不治免租期                   |
| 网络闭锁准入             | F 阶段重连会冲掉闭合，成功率约 50%；推迟到 P6 前单独评估             |
| 调 `needMultiplier` 数值 | 治不了清零：乘子再大，升阶后 `classAge=0` ⇒ `buffer=0` ⇒ need 仍是 0 |
| 只换参照量（A 原式）     | 见上：`buffer` 乘子保留 ⇒ 免租期仍在 ⇒ G-A 的 P0 抬不起来            |
| 只去掉 `buffer` 乘子     | 升阶后立即按全额判定，`belowNeedLimit` 内被弹回 ⇒ 无迁移、只剩抖动   |

**版本轴**：`rules-v6` / `engine-v0.4.0` / `stratify-config-v3`（含 v2→v3 迁移，
迁移填 `referenceMode:'own'` 以保持语义不变，v6 默认配置显式设 `'class'`）；
golden fixture 全套重算；`docs/changes/0008` 记录；03 §6/§7 与 `rule.md` 同批修订。

**W1 机制门禁**（不看聚类，先确认机制活了）：

| 门禁 | 判据                                                | 含义                     |
| ---- | --------------------------------------------------- | ------------------------ |
| G-A  | baseline 3650 tick：`P0(w3) ≥ 0.15` 且 `mUp ≤ 0.60` | 底层不再被抽空、扶梯降速 |
| G-B  | 5 参数 × 3 档小扫：P4 跨度 ≥ 0.40                   | 形状能被参数拉开         |
| G-C  | `‖P(w2b) − P(w3)‖₁ < 0.10`                          | 进入平稳态，不是继续爬梯 |
| G-D  | `referenceMode` 双值可切换且 `'own'` 与 v5 逐位一致 | 消融契约成立             |

G-A/G-B/G-C 任一不过，说明该机制不足以撑起 G1.5，此时叠加**位移准入**作为第二级
（进入目标阶级需击败该阶级边界在位者，被击败者降级），而不是继续调参。
在相对单位已就位的前提下再加位移，成本很低。**位移准入不与 W1 同批落地**（见 §8 D-08）。

### W2 预注册与确认轮（1 天准备 + 约 2 小时机器时间）

网格重组（约 40 个 cell，30 配对种子，3650 tick）：

1. **分离面定位**：`envExponent ∈ {0, 0.3, 0.5, 0.7, 1.0, 1.2, 1.5, 2}`（补 2.4 的空档：
   0.5→1.5 之间 P4 从 0.88 掉到 0.34，没有采样点）
2. **参照强度**：`need.referenceSmoothing` α 三档 × `ψ` 尺度三档
3. **持有标准**：`bufferDays ∈ {10, 30, 60}`、`belowNeedLimit ∈ {7, 14, 30}`
4. **底层占位**：`needThreshold` 三档，检查 P0 是否被托住
5. **确认种子**：`p15r3-seed-001 … p15r3-seed-030`（D-07 已定：新取，与探索轮
   `p15-seed-001…030` 不重叠；07 §6.1 探索/确认分离）

**判定协议（预注册写死）**：

- k 由轮廓系数在 `k∈[2,5]` 内选择，但**必须同时满足** k=2 的 ARI median ≥ 0.70；
  否则直接判定"无宏观二态"，不得退而报告 k=4/k=5 的结果充当通过。
  ——这一条是本次诊断的直接产物：不允许用更细的切分绕过"最粗二分类不存在"。
- 簇级：≥2 个簇的 bootstrap Jaccard ≥ 0.75，且每簇 ≥5 run；
- 至少 1 簇不是全死亡/空网络；
- 均值场方向一致。

## 7. 不做清单（红线）

1. **不引用 0.702** 声称通过——07 §8.1 取 min，这是已写进契约的口径。
2. **不降低 0.70 阈值**。若要改阈值，必须先改 07 §8.1 并说明理由，且新旧口径同时报告。
3. **不在同一批次中途更换聚类实现**。实现标识随预注册冻结，换实现=新 `experimentId`。
4. **不用"格点区分度达标"替代"结构类别成立"**。`needThreshold=0.3` 区分度达标却 60/60
   落在同一簇，说明数值差异 ≠ 结构差异。
5. **不把"参数开关造出的结构"当作涌现**。`envExponent=0` 得到的封闭分层必须在报告里
   标注为"机制关闭条件下的对照"，不能作为"结构自发涌现"的证据。
6. **不用固定乘子阶梯替代相对参照**。`needMultiplier` 是常数阶梯，加大会掩盖 R1，
   但升阶后 `buffer=0` 仍然免税；这不是修复。
7. **不让 `refIncome` 取同期值**。参照量必须来自 `t-1` 的宏观量，否则引入
   agent 处理顺序依赖，破坏回放与并行一致性（AGENTS 约束 4）。
8. **不跳过 W1 机制门禁直接跑 W2**。机制没生效就重跑，只会得到又一份连续统。

# P6-04b 正式 live/mock/random 对照（2026-11-05）

- 目的：按 07 §11 在固定规则与初始人口下，比较 `mock-weighted-v1`、
  `random-uniform-v1` 与 `jev_live`，并检验 `promptStyle=neutral` /
  `survival_hint` 的提示处理；**单集合 10 seed，描述性，不是确认或校准**
- 预注册：`out/p6-04b-formal-prereg.json`，experimentId `p6-04b-formal-9a8febe2`，
  designHash `sha256:9a8febe2…`
- 结果：`out/p6-04b-formal-analysis.json`（`sha256:94570791…`）
- 结论：`no-structural-evidence`；live 结构接近 mock、远离 random；
  `survival_hint` 在次要指标上出现强信号，但未通过预注册主指标

## 1. 方法

1. 配置：`rules-v11`、40 人、730 tick、`decision.interval=30`（25 个决策点）；
   warmup=365，分析窗口 `w1=[365,729]`（365 日）。
2. 种子：`p6-04b-formal-seed-001…010`（新 seed，与 pilot 的
   `p6-04b-live-seed-001` 不重叠）。
3. 分组（每组 10 run，共 40 run）：mock、random、live+neutral、
   live+survival_hint。mock/random 使用相同 seed 派生的人口与随机流；live 通过
   `JevLivePolicy` 调用网关，逐决策保存概率、选择、usage、延迟、回退与 rawResponse。
4. 预算：25,000 calls / 45M input tokens / 240 min，并发 4；live 实际
   19,799 个到期决策、8 次 `upstream_5xx` 回退（0.040%）、0 缺失 usage、
   单一响应模型 `jev-1.13-free`。
5. 统计（运行前冻结）：主指标 `TV(P)`≥0.10；10,000 次配对 bootstrap（seed
   20261105）；有符号 `ΔG` 的 100,000 次符号翻转置换；方向一致率≥0.90；
   候选-基线 D 需 100% 超出同策略跨种子 D95；5 个比较做 BH（q=0.05）。
   TV 非负，不做符号翻转检验（预注册已写明）。

- baseline D95：mock **0.2156**、random **0.1183**。

## 3. 判读

- **live vs mock**：TV(P) 0.017–0.025，D 中位数 0.034（neutral）/ 0.191
  （survival），均低于 mock 跨种子 D95 0.2156；live 的 w1 结构落在 mock 的
  跨种子波动范围内，没有可检测的结构差异。这与 1-seed pilot（TV 0.0152）
  方向一致，但样本量仍不足以做确认。
- **live vs random**：TV(P) ≈0.38、D 0.15–0.21，100% 超出 random D95，说明
  live 行为不是均匀随机。但 ΔG 方向一致率只有 0.70–0.80（<0.90），BH 校正后
  p=0.16–0.24；按 07 §8 全套条件仍不构成结构差异证据。
- **promptStyle 是强处理**：`survival_hint` 把中位 Mup 压到 0.000、O 压到
  0.143、S 升到 0.354，而阶级分布几乎不变（TV(P)=0.0311）。预注册主指标
  TV(P) 与方向指标 ΔG 都没有捕获这一变化，因此不能改判为“结构变化”；它更像
  行为/网络层面的处理效应，应作为下一轮预注册的假设（例如把 Mup/S/O 设为主
  指标或分层指标），而不是事后挑选有利指标。
- **质量**：8 次回退均为 `upstream_5xx`（0.04%），单一模型，无缺失 usage，
  未触发排除；max latency 25.9 s 提示尾部延迟仍需在更大批次观察。

## 4. 限制

- 单个 10-seed 集合，未做独立确认种子集；最高只能标 descriptive。
- 主指标 TV(P) 对阶级占比敏感，对流动/网络/制度变化不敏感；本轮
  `survival_hint` 的强信号正好落在其盲区。
- 只有 40 人 × 730 tick 的缩小视野；窗口 w1 仅 365 日，不能外推到 3650 tick。
- 免费网关的模型版本可能漂移；本轮响应模型单一，但不保证跨批次稳定。
- 回退率低不等于模型输出可靠；重测信度只覆盖单个 state 的 20 次重复。

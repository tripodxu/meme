# P1.5 descend 触发条件探针：策略敏感性的来源（2026-11-04）

> **性质：探索层**（07 §6.1）。不构成 G1.5/P6 证据，也不改变生产策略或 rules-v10
> 结算语义。种子 `p15d-*` 与 `p15b-*`/`p15c-*`/`p15r3-*`/`p15r4-*` 均不重叠。
>
> **结论**：路径锁定是否出现由 **descend 的触发条件**（`belowNeedStreak>=7` 门控
> vs 无条件）决定，而不是 descend 权重。`random-uniform-v1` 的均匀选择天然包含
> 无条件下降，这解释了它为何不复现 mock 的锁定。锁定是**策略-规则交互**，
> 不是 rules-v10 的结构性涌现分岔。

## 1. 问题

mock 策略下 `up` 路径（w=0 预热 → w_mid）会抽空 class0/1 并锁定；`random-uniform-v1`
下同一设计 0/9 cell 锁定。一个候选解释是“random 的下降率更高”。若该解释成立，
在保持其它 mock 权重不变的前提下提高 descend 权重，应能在某个阈值处解除锁定。

## 2. 设计

- 自定义探索策略（`explore-descend-*`）：
  - `accumulate=1`；`ascend=0.8`（`value >= 1.5×ascendCost` 时）；`compete=0.1`；
  - `descend=d`，分两档触发条件：
    - `streak`：仅当 `belowNeedStreak >= 7`（mock 原条件）；
    - `always`：只要 descend 合法即可选。
  - 加权抽样使用 `R(seed,tick,agentId,"explore_descend",0)`（新增探索层 tag，
    不进入生产策略）。
- 其余同分叉实验：`share=0.5`、`w_mid=25`、ic-middle、`up`/`down`/`control`、
  预热 1825 + 后段 1825 tick、5 个 `p15d-*` 种子。
- `d ∈ {0, 0.2, 0.5, 0.8, 1.2, 2, 4}`；`d=1.2` 接近 mock 原权重，`d=0` 为无下降对照。

## 3. 结果

### 3.1 `streak` 门控（mock 原条件）

| d   | up locked | down locked | control locked | mUp up | mUp down | mUp control |
| --- | --------- | ----------- | -------------- | ------ | -------- | ----------- |
| 0   | 1.000     | 0           | 0              | 6.0    | 31.8     | 54.4        |
| 0.2 | 1.000     | 0           | 0              | 4.6    | 30.8     | 51.4        |
| 0.5 | 1.000     | 0           | 0              | 6.2    | 31.2     | 57.6        |
| 0.8 | 1.000     | 0           | 0              | 5.6    | 32.8     | 53.8        |
| 1.2 | 1.000     | 0           | 0              | 4.8    | 32.6     | 53.0        |
| 2   | 1.000     | 0           | 0              | 6.4    | 37.4     | 54.2        |
| 4   | 1.000     | 0           | 0              | 2.6    | 38.8     | 54.0        |

**提高 descend 权重（0→4）没有解除锁定**；`up` 的 mUp 始终在 2.6–6.4，底层为空。

### 3.2 `always`（无条件下降）

| d   | up locked | down locked | control locked | mUp up | mUp down | mUp control |
| --- | --------- | ----------- | -------------- | ------ | -------- | ----------- |
| 0   | 1.000     | 0           | 0              | 6.0    | 31.8     | 54.4        |
| 0.2 | 0         | 0           | 0              | 600.2  | 601.4    | 1054.2      |
| 0.5 | 0         | 0           | 0              | 763.2  | 757.6    | 1315.8      |
| 0.8 | 0         | 0           | 0              | 796.4  | 800.6    | 1386.4      |
| 1.2 | 0         | 0           | 0              | 847.4  | 833.0    | 1445.6      |
| 2   | 0         | 0           | 0              | 841.4  | 838.8    | 1361.8      |
| 4   | 0         | 0           | 0              | 812.6  | 809.8    | 1346.8      |

**只要 descend 无条件可触发，哪怕权重仅 0.2，锁定也消失**；阈值在 d=0 与 0.2 之间。
`d=0` 与 3.1 的 d=0 完全一致（同一策略），作为对照通过。

## 4. 解释

- 锁定由**下降时机**控制：`streak` 门控让 `up` 路径在 `w=0` 预热中先把底层抽空，
  之后即使把 descend 权重升到 4，也没有“可下降的底层个体”来恢复组成。
- `always` 条件下，少量无条件下降就持续把个体送回底层，阻止抽空；权重再大只是
  提高环流速度（`up` 的 mUp 提高约两个数量级，`down`/`control` 约一个数量级），
  并不会改变“是否锁定”。
- `random-uniform-v1` 的均匀选择包含无条件 descend，因此在同一设计下天然处于
  `always` 一侧，解释了它 0/9 cell 锁定的负结果。
- 因此锁定的控制参数是**策略的下降触发条件**，不是 rules-v10 的配置参数；
  不能称为规则层涌现分岔。跨策略比较 mUp 也不可直接进行（例如 d=0.2 时
  `up` 约 100 倍、`down`/`control` 约 19 倍）。
- **对 G1.5/W4 的含义**：W4 的 180 run 同样使用预注册的 `mock-weighted-v1`。
  后续策略敏感性（changes/0018）用 random 覆盖 W4 格点：A vs B∪C 的聚类保留，
  但 B/C 方向预测失败。因此本探针与 0018 一致地表明：**结构分裂可跨策略复现，
  方向/机制解释不能**；G1.5 的结论范围仍是预注册的 mock 策略。

## 5. 限制

- 5 个种子、仅 ic-middle、`w_mid=25`、mock-like 其它权重；未测 Jev。
- 自定义策略使用 `explore_descend` 探索 tag，不属于生产策略；`d=0.2` 与 random 的
  实际下降概率只是机制一致，未做精确等价校准。
- 未证明在 `always` 条件下是否存在其它路径效应；本轮只回答“锁定是否出现”。
- 未检验 W4 的 A/B/C 体制在 `always`/`random`/Jev 策略下是否保持；不得把本探针
  的结论外推为“G1.5 结构是策略无关的”。

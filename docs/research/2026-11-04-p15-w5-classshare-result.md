## 1. 设计

- 6 个 W4 cell：A-share1、B-w10/w15、C-w60/w80/w100。
- 30 个全新种子 `p15r5-seed-001…030`，`mock-weighted-v1`，3650 tick。
- 特征集：仅 5 个阶级占比（w3），z-score(pooled)；k 固定为 3。
- 门槛：ARI median/min ≥0.70；temporalConsistency（w2b↔w3 同簇）≥0.80；
  每簇 ≥5 run；方向预测 A/B/C；7300 tick 收敛子集（10 seeds/cell）同簇率 ≥0.80。

## 3. 诊断：失败来自 B/C 边界的慢收敛

temporalConsistency 的 38 个失配按 cell 分布：

| cell     | 同簇/总数 | 失配方向           |
| -------- | --------- | ------------------ |
| A-share1 | 30/30     | —                  |
| B-w10    | 20/30     | 10 个 2→1          |
| B-w15    | 8/30      | 22 个 2→1          |
| C-w60    | 28/30     | 1 个 0→2、1 个 2→1 |
| C-w80    | 28/30     | 2 个 0→2           |
| C-w100   | 28/30     | 2 个 0→2           |

w2b（1825–2554）时 B 还停在 C 一侧，w3（2555–3284）才进入 B 一侧；B-w15 最明显
（22/30）。这不是随机噪声，而是**开放体制的慢收敛**：B 边界在 3650 tick 内尚未
稳定，temporal gate 如实抓到了它。

进一步跑 B-w15、C-w60 的 30 seeds × 10950 tick（对齐 W5 的 3650 簇）：

| cell   | 10950 同簇率 | 说明                                    |
| ------ | ------------ | --------------------------------------- |
| B-w15  | 25/30        | 5 个从 C 侧进入 B；**30/30 最终都在 B** |
| C-w60  | 3/30         | 28 个从 C 进入 B，2 个留在 C            |
| C-w80  | 8/30         | 22 个从 C 进入 B                        |
| C-w100 | 19/30        | 11 个从 C 进入 B                        |

C 类不是稳定吸引域：`scarcityWeight` 越低，越容易在更长时间里滑回 B；
即使 C-w100 也有 11/30 滑回 B。**A/B/C 三类是有限视野现象，A vs B/C 两类才是
稳健结构。** 这与 W4 的 k=2、changes/0021 的“闭合体制多吸引域、开放体制记忆擦除”
一致。

## 4. 结论

- W5 **未通过**；P6-05 的 ≥3 类仍未满足，不能声称三类结构已确认。
- 第三类（C）在 class-share 空间可见，但它是 B/C 连续统上的慢收敛区域，不是
  稳定吸引域；继续加种子/加长视野不会把它变成独立类，反而会更清楚地看到它滑回 B。
- 要产生稳健的第三类，必须改变规则，让 C 变成一个**被钉住的盆地**：
  阶级配额/容量、网络闭锁阈值、占用棘轮/滞后或位置外部性（rules-v11）。
  这不是再调一个参数或再换一个特征集能解决的。
- 不应通过放宽 temporal gate、删除 B-w15/C-w60、或改用更短视野来“救” W5；
  这些都会把瞬态包装成结构。

## 3. 优化项

- 为 `PARAM_DEFINITIONS`/`NUMERIC_CONSTANTS` 增加 golden 快照，冻结参数名、单位、域与护栏标记。
- 冻结 `DEFAULT_RUN_CONFIG`，并让 `createDemoConfig` 产出后执行一次校验。
- 核心纯度加固：core 使用不含 Node types 的 tsconfig；ESLint 增加 `process/Buffer/setTimeout/setInterval/crypto` 等限制。
- CI 补 08 §10 承诺的依赖与密钥扫描。
- 补测试：稀疏数组拒绝、`gain <= loss` 性质、注册表/validator 边界一致性、配置叶子覆盖、真正的配置 round-trip。
- 清理死代码与版本常量：`SCHEMA_VERSION`、未使用错误码、`requestHash`/验证报告 hash 的 domain。
- fixture 中 params 向量的 `unit: "share"` 改为 `unit: "ratio"`。

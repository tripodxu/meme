# 0006 目标修订：从“三类结构”到“2 体制 + 连续统”

- 状态：accepted（2026-11-11，规则负责人选择 D1）
- 决策者：徐鼎
- 关联：`docs/reviews/2026-11-11-p6-05-rule-design-review.md`、changes/0057/0058/0059/0061/0063/0064
- 取代：`rule.md` 规则 57 的“三类结构”验收口径；不取代任何结算规则
- 影响：G6 的结构目标、`docs/07` §8.2、`docs/01` §9、P6-06 确认轮

## 背景

P6-05 至 P6-05e 的五轮全特征聚类都没有得到可复现的第三类结构：

| 轮次     | k=3 簇      | ARI median | silhouette | 同簇率 |
| -------- | ----------- | ---------- | ---------- | ------ |
| P6-05    | [30,118,32] | 0.491      | 0.344      | 0.667  |
| P6-05b   | [136,17,27] | 0.291      | 0.297      | 0.550  |
| 搜索验证 | [74,97,9]   | 0.157      | 0.241      | 0.683  |
| P6-05c   | [72,39,9]   | 0.182      | 0.215      | 0.675  |
| P6-05d   | [76,3,41]   | 0.094      | 0.152      | 0.650  |

P6-05e（D3）进一步显示：40 人下出现的第三簇在 200 人下只剩两个簇，
1000 人下 30/30 全部落在同一簇；第三簇更像有限样本噪声，而不是随规模
持续的结构。继续把“≥3 类”作为 G6 目标，会诱导继续在状态机上加旋钮、
换种子或换 k——这正是预注册纪律要禁止的。

## 决策

把 G6 的结构目标从**“至少三类显著不同的结构指纹聚类”**修订为
**“2 体制 + 连续统”**：

> 在预注册的全特征聚类中，存在一个可复现的 **k=2** 划分；两个体制在
> 预注册的序参量上有实质差异；同时 **k=3 不产生稳定第三簇**。两个体制
> 内部的连续变化被报告为“连续统”，不再要求第三个离散类。

### 新验收口径（07 §8.2）

确认轮（P6-06）沿用 P6-05 的 6 个参数区域、11 维全特征、Ward-LW、
20 次稳定性 shuffle、终端窗口与 14600 followup；仅把聚类目标改为 k=2，
并要求：

1. **k=2 稳定**：两个簇各至少 5 个 run；ARI median ≥0.70（同时报 min）；
   silhouette ≥0.35；14600 同簇率 ≥0.80。
2. **反预设**：至少一个簇包含 ≥2 个参数区域（不得两个簇各对应单一预设）。
3. **体制差异**：两个簇的质心在预注册序参量上至少一项达到
   `|ΔO| >= 0.10` 或 `|ΔS| >= 0.10` 或 `TV(P) >= 0.10`；方向必须与
   预注册假设一致。
4. **无稳定第三簇**：k=3 不满足“所有簇 ≥5 且 ARI median ≥0.70 且
   同簇率 ≥0.80”中的任一项；k=3 结果必须同时报告。
5. **独立确认**：使用全新 seed 集预注册；旧 P6-05 数据不得追认通过。
6. **新旧同报**：任何 G6 结论必须同时报告旧的 k=3 口径结果，明确
   “旧口径未通过、新目标下 k=2 是否通过”，不得只报有利口径。

“连续统”的操作定义是**不存在稳定第三簇**；两个簇内部的连续分布
（序参量 IQR、质心距离、中间态 run 数）作为描述性证据报告，不设额外
阈值。200/1000 人口的结果作为边界条件报告，不进入 G6 判定。

## 不变的部分

- 结算规则、`rules-v13`、配置/状态 schema、参数注册表、哈希域全部不变。
- 07 §8 的效应门槛、30+ 配对种子、独立确认集、质量检查、预注册纪律不变。
- G6 仍未通过；本 ADR 只改变“通过”的定义，不把任何旧结果改判为通过。
- 不得声称参数已校准或结构已涌现；仍须满足 07 §8–§12 的完整验收。
- 不得调 k、换特征、事后挑 seed/cell 或放宽阈值来凑 k=2。

## 后果

- 正面：目标与五轮证据一致；停止为“第三类”继续加机制旋钮；把资源
  转向 2 体制的可复现性与连续统描述。
- 负面/限制：这是目标修订，不是新发现；k=2 在 P6-05e 的 200 人数据上
  silhouette 只有 0.252，说明 2 体制也未必稳健；P6-06 可能仍不通过。
- 验证：P6-06，6 个 P6-05 参数区域 × 30 个全新 seed × 40 人 × 10950
  tick（每 cell 前 10 续跑 14600），k=2 验收 + k=3 无稳定第三簇检查。
  若 P6-06 未通过，G6 仍未通过，下一步才讨论 D2（引入行为异质性）。
- 文档：`rule.md` 52/57、`docs/07` §8.2、`docs/01` §9、`docs/12`、
  `docs/README.md`、`AGENTS.md`、changes/0065。

## 备选方案

| 方案                         | 结果                                                |
| ---------------------------- | --------------------------------------------------- |
| 继续追求三类结构（旧目标）   | 五轮均失败；继续调参违反预注册纪律                  |
| D2 引入行为/阶级异质性       | 范围大、需新机制与预算；留作 P6-06 失败后的下一 ADR |
| 直接降低 07 阈值让旧结果通过 | 违反 AGENTS 9；新旧口径混报；不采用                 |

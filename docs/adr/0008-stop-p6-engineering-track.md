# 0008 停止 P6 结构目标，转工程轨道

- 状态：accepted（2026-11-11，规则负责人选择“停止 P6”）
- 决策者：徐鼎
- 关联：ADR 0006/0007、changes/0057/0058/0059/0061/0063/0064/0066/0068
- 影响：P6 实验计划、G6 状态、P3/P4/P5b/P7 的启动前置条件
- 不改变：任何结算规则、参数、schema 或已发布证据；`rules-v15` 保持当前版本

## 背景

P6 的结构目标是找到可复现的宏观结构指纹（旧口径 ≥3 类，D1 后为
“2 体制 + 连续统”）。截至 2026-11-11，全部预注册轮次均未通过：

| 轮次         | 结果                                                          |
| ------------ | ------------------------------------------------------------- |
| P6-05 / 05b  | k=3 不稳定（ARI 0.491 / 0.291，silhouette 0.344 / 0.297）     |
| 参数搜索     | 9,600 粗筛 + 240 验证，`no-stable-region-found`               |
| P6-05c / 05d | θH 与制度状态机均未产生第三簇；θR>0 塌到 closed 单态          |
| P6-05e（D3） | 第三簇随人口从 200 到 1000 消失，更像有限样本噪声             |
| P6-06（D1）  | k=2 很强（ARI 1.000、差异 0.723），但 k=3 仍稳定（ARI 0.768） |
| P6-07（D2）  | 行为异质性 C–F 相对 A 的差异均 <0.10，k=2/k=3 簇跨全部 cell   |

P6-01 有 1 个确认效应（`needThreshold=0.9`，TV(P)=0.1553），P6-02/03/04
的其余结果均为 exploratory 或无结构证据；这些都不构成 G6 通过或校准。
继续在现有规则族内加机制旋钮，已经反复触发“为达标而调参”的风险，
且每轮成本高、边际信息递减。

## 决策

1. **停止 P6 结构目标**：不再新增 P6 预注册轮次，不再为“第三簇/2 体制”
   调整 θH/θR/θS/H/share/w/k/seed/阈值或新增同类机制旋钮。
2. **G6 保持未通过**：不追认任何旧结果，不把 P6-06 的 k=2 或 P6-01 的
   单参数效应写成 G6 通过；不声称参数已校准、结构已涌现或现实因果。
3. **释放工程轨道**：P3（前端）、P4（Worker/D1/R2）、P5b（上传/云端）、
   P7（发布硬化）不再以 G6 通过为前置条件，可按 `docs/01` §9/§10 的
   依赖关系启动；工程产物不得被表述为科学验收。
4. **保留证据与代码**：全部 P6 产物、`rules-v15`、行为异质性与制度状态机
   代码保留，供审计和未来复用；默认配置仍与 v13/v14 逐位一致。
5. **重新立项门槛**：若未来重启结构目标，必须新立 ADR，提出与已失败机制
   不同的假设，使用全新预注册与全新 seed；旧 P6 结果不得追认或复用为
   确认证据。

## 后果

- 正面：停止低边际收益的机制搜索；把资源转向可交付的工程轨道；预注册
  纪律与失败记录完整保留。
- 负面/限制：G6 永远不会以“通过”状态交付；产品不得声称社会结构已被
  验证；P6 的失败结论仍是项目已知限制，必须写入用户文档与发布说明。
- 工程口径：P3/P4/P5b/P7 可以演示模拟与实验管理能力，但 UI/API 文案
  必须区分“可运行/可回放”与“结构已校准”；不得用 UI 暗示 G6 通过。

## 备选方案

| 方案                          | 结果                                                               |
| ----------------------------- | ------------------------------------------------------------------ |
| 继续 D1 第三簇定义修订        | 需新 ADR + 全新确认轮；P6-06 的 66/84 分裂接近体制级，难以诚实细化 |
| 继续 D2 调 sigma/敏感性       | 本轮已无效应；继续调参违反预注册纪律                               |
| 另立新机制 ADR 后继续 P6      | 保留为未来选项，但不在本轮自动启动                                 |
| 停止 P6，转工程轨道（本 ADR） | 接受 G6 未通过，保留证据，启动 P3/P4/P5b/P7                        |

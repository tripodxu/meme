# 00 项目章程与范围

## 1. 项目目标

构建一个用于研究规则敏感性与社会结构涌现的实验台，使用户能够：

- 配置规则、初始人口和决策策略，运行并单步观察仿真；
- 检查个体为何行动、财富如何变化、阶级如何流动；
- 从同一检查点执行微扰、配对和消融实验；
- 在浏览器完成小规模交互，在 VPS 完成批量扫描；
- 导出足以复核结论的配置、版本、决策、事件和聚合指标；
- 在 Cloudflare 部署公开界面与受控数据服务，而不依赖 Worker 做重计算。

## 2. 产品原则

1. **规则先于界面**：没有可测试的核心结算，不做宏观结论页面。
2. **模型不做算术**：Jev 只选行动，所有行动由代码枚举，所有后果由引擎计算。
3. **涌现不等于随机**：稳定区应吸收微扰，临界区才可能放大路径差异。
4. **证据先于标签**：结构标签必须附原始指标、窗口和种子分布。
5. **同源复用**：浏览器、Node/VPS、测试使用同一核心，不复制结算公式。
6. **默认离线可用**：无后端、无 API Key 时仍可用 mock 完整运行和回放。
7. **实验可追溯**：缺少版本、种子、配置哈希或决策来源的结果不得进入正式报告。

## 3. 范围

### 3.1 MVP 必须包含

- 固定阶级数默认 5、固定人口、无生育、无迁移、死亡后退出；1 tick = 1 个模拟日。
- 日常积累、需求线、`needMultiplier` 阶级持有成本、主动升降、被动跌落、重返减免、竞争、初始年龄分布、寿命和死亡。
- 社会关系网络、动态机会、开放度、可寻址随机流（v2 引入）；v3 在此之上增加调整后 S、365 日 Mup/Mdown 和结构指标。
- `mock` 决策器、Jev `Choice` 决策器、非法行动安全回退、决策日志。
- 运行/暂停/单步/重置、参数校验、核心图表、个体检查器、导入导出和回放。
- Worker 静态托管、同源 Jev 代理、D1 聚合数据、R2 分块 artifact。
- VPS CLI、全局并发/限流、检查点恢复、预算熔断、分批上传。
- 配对种子参数扫描、微扰实验、五个消融组（含 ψ=1）及校准报告。

### 3.2 明确不在 MVP

- 生育、家庭、迁入迁出、地理空间、多国家、多币种或现实政策建议。
- 让 Jev 直接生成代码、财富、胜率、网络、宏观指标或社会标签。
- Durable Objects、Queues、Redis、PostgreSQL、实时多人协作和 Worker 服务端长时推进。
- 宣称模型能预测现实社会，或将仿真指标解释为现实因果证据。
- 未经校准就发布“三种结构已稳定出现”等结论。
- 为追求视觉复杂而引入重型 3D、大型状态库或无必要微服务。

## 4. 角色与职责

一人可兼任多个角色，但每项交付只能有一个最终负责人。

| 角色 | 责任 | 不得单独决定 |
|---|---|---|
| 规则负责人 | 规则语义、默认值、校准和结构判异 | 绕过测试直接改结算 |
| 核心开发 | 状态机、RNG、结算、快照、指标 | 修改 Jev/HTTP 公共契约而不通知 |
| 决策层开发 | 合法行动、prompt、客户端、重放和成本记录 | 在核心中调用网络 |
| 前端开发 | 交互、可视化、离线运行和导入导出 | 在前端复制规则公式 |
| 后端开发 | Worker、D1/R2、认证、幂等和保留策略 | 存储明文密钥 |
| Runner/运维 | VPS、部署、备份、监控、故障和恢复演练 | 无预算运行真实模型批量任务 |
| 评审者 | 核对契约、测试证据和实验可复现性 | 仅凭演示截图验收 |

## 5. 里程碑完成定义

### M1：确定性核心

- 59 条规则均有实现映射、测试或明确的后续校准项。
- 相同版本、配置、初始状态和 mock 决策输入产生相同最终状态哈希。
- 快照恢复与连续运行一致；所有数值不变量通过性质测试。
- 无网络、DOM、Node、Worker 或 wall-clock 依赖进入 `src/core`。

### M2：可用交互 MVP

- 无后端可运行 mock；真实 Jev 可经 Worker 同源代理运行。
- 每次行动可解释到合法候选、模型响应/回退原因和结算事件。
- 可导出并重新导入回放；图表显示指标定义和窗口，不只显示终局。

### M3：可批量实验

- VPS 进程被终止后可从最近完整检查点恢复，不重复上传已确认数据。
- 参数扫描至少 30 个配对种子，输出分布、波动区间和五个消融组（含 ψ=1）。
- 找到并冻结至少三类互不相同的结构指纹聚类（不是三组预设或同一状态的多个标签），且验证稳定区微扰吸收；未达到则规则 v3 不得标记校准完成。

### M4：可公开发布

- CI、workerd+D1 集成、真实 Jev 小额冒烟、备份恢复和故障注入全部通过。
- 密钥、写令牌、预算、限流、保留策略和运维手册经检查。
- 支持回滚到上一 Worker 版本，旧导出仍可按版本读取。

## 6. 关键已知风险

| 风险 | 处理 |
|---|---|
| 默认参数只产生单一结构、顶层塌缩或完全随机分叉 | P1.5 做均值场/可达性预研；先修 needMultiplier、Congestion 边界、Mup/S 口径，再按 07 校准，不伪造验收 |
| Jev 延迟、费用或非确定性破坏实验 | 预算、限流、完整日志、mock 对照和决策重放 |
| 人口规模导致 O(N²) 网络/候选计算 | 候选采样、分块、性能门禁；禁止无界全连接 |
| 浮点或更新顺序造成伪差异 | 固定顺序、可寻址 RNG、统一运行时、golden fixture |
| D1 写放大和 Worker 资源限制 | 聚合入库、R2 大日志、批量幂等、VPS 重计算 |
| 规则文档与代码漂移 | 规则映射测试、版本字段、PR 强制同步文档 |

## 7. 待验证而非既定事实

- 三组结构参数区域及其阈值。
- Jev 策略是否比 mock 产生有解释力的行为差异。
- 具体可承载人口、ticks、并发和单位实验成本。
- Jev 当前模型名、价格、限流和上下文上限；接线和发布前以官方文档及实测响应为准。
- Cloudflare 当前套餐额度；部署前复核官方限制，不在代码里假设永久不变。

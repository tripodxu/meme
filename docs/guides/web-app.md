> 状态：P3 完整双界面工作台（2026-11-18，changes/0083/0084）。G6 未通过，界面内所有预设与剧本均为“未校准演示”。

## 启动与自动化验证

```bash
pnpm install
pnpm dev:web          # 默认 http://localhost:5180
pnpm test:e2e         # jsdom 快速 DOM E2E
pnpm test:e2e:browser # Playwright 真实浏览器自动化 E2E
pnpm build:web        # 构建静态站点至 dist-web/
```

## 双核心表面与五个科研工作区

- **✦ 交互沙盒剧场（Living Stratification Arena）**：五阶层 Canvas 2D 动态生态画布（财富晋升阶梯 / 社会关系星群双布局）、4 组未校准探索剧本、主角化身附身与决策日「命运抉择行动卡」、单字段平行宇宙微扰分叉与实时社会演化编年史。
- **◈ 精密科研试验台（Sociology Observatory）**：
  1. **实验设置**：预设、基础规模、七维机制旋钮、五阶层向量参数编辑器（含 `classShares` 一键归一化）、制度滞回细节与实时数学 Sparkline 预览；启动前校验并显示 `configHash`/`paramsHash`。
  2. **实时总览**：五维窗口均值指纹雷达、阶级结构堆叠、财富基尼/对数中位数切换 + 实时洛伦兹曲线、双向流动、网络结构、开放度/动态机会、按方向分组竞争损耗、累计死亡 + 存活剩余寿命直方图、阶级转移矩阵、行动分布、窗口区间缩放与 CSV 导出。
  3. **个体检查器**：千人分页花名册（零焦点丢失）、生存与阶级任期档案、决策 X 光（含脱敏 `rawResponse`/哈希折叠 JSON）、财富变动复式账本与自我中心关系网（Ego-Network）。
  4. **回放与对比**：导出完整 bundle、导入校验、逐帧回放、历史周期快照点回滚跳转、双宇宙轨迹叠加对比，以及 `>=30` 配对种子批次摘要森林图（Forest Plot，`<30` 自动阻断显著性区间渲染）。
  5. **实验管理**：IndexedDB v3 分块快表（`snapshots/stats/decisions/events` 分块计数）、同标签页刷新自动恢复、存储配额估算、失败诊断包导出与双科研主题切换。

## 键盘

- `0`：切至「✦ 交互沙盒剧场」
- `1`–`5`：切至试验台对应工作区
- `Space`：暂停/继续（就绪时开始）
- `N`：单步 +1 tick
- `E`：导出当前 run

输入框内不触发快捷键。

## 数据与限制

- 离线 run 使用 `local-<uuid>`，只支持导出/回放；MVP 不支持把离线结果直接采纳为
  云端权威记录。
- IndexedDB 采用 v3 分块原子写入（`runs_meta` + `run_chunks`）；同标签页刷新会根据 `sessionStorage` 中的 `stratify.lastRunId.v1` 自动校验并恢复上次实验进度（无完整分块时如实提示，绝不伪造恢复）。
- 导出包含配置、初始/最终快照、统计、事件与决策日志；决策日志超过 5 万条会截断
  并在界面标记。
- `jev_live` 可通过同源 `/api/jev` 代理使用：Key 只驻留内存（密码输入、不回显），
  请求经 `Authorization` 头转发；写入存储、导出 bundle 或日志都会被视为缺陷。
  需要 Worker 已配置 `JEV_ALLOWED_MODELS`，并承担真实调用费用；认证/预算/熔断失败
  会停止 run，不会静默回退继续。浏览器 live 结果不是 Node runner 的权威对照。
- 单次运行对比没有 30 种子配对波动区间，界面只显示“描述性差异”，不得据此声称
  结构显著改变。
- 浏览器界面不是校准证据；结构结论以 `docs/07` 的预注册与统计验收为准。

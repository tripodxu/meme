# 浏览器工作台快速开始

> 状态：P3 前端 MVP（2026-11-11）。G6 未通过，界面内所有预设均为“未校准演示”。

## 启动

```bash
pnpm install
pnpm dev:web
```

默认 <http://localhost:5180>。生产构建：

```bash
pnpm build:web
```

产物在 `dist-web/`，是静态站点；不依赖 Worker 即可运行离线 mock。

## 五个工作区

1. **实验设置**：预设、人口/tick/决策间隔、seed、年龄模式、开放度、位移份额、
   占用锚定与行为异质性参数；启动前校验并显示 configHash/paramsHash。
2. **实时总览**：结构指纹、阶级结构、财富、流动、网络、开放度/机会、竞争、
   寿命、转移矩阵、行动分布与最近事件。
3. **个体检查器**：名册筛选、属性卡、决策概率、核心执行记录、事件账本与邻居。
4. **回放与对比**：导出完整 bundle、导入并校验、从头回放、描述性并排指标。
5. **实验管理**：IndexedDB 本地 run 注册表、存储配额、诊断下载、主题切换。

## 键盘

- `1`–`5`：切换工作区
- `Space`：暂停/继续（就绪时开始）
- `N`：单步 +1 tick
- `E`：导出当前 run

输入框内不触发快捷键。

## 数据与限制

- 离线 run 使用 `local-<uuid>`，只支持导出/回放；MVP 不支持把离线结果直接采纳为
  云端权威记录。
- IndexedDB 每 2 秒至多保存一次完整 bundle；刷新后在“实验管理”手动载入。
- 导出包含配置、初始/最终快照、统计、事件与决策日志；决策日志超过 5 万条会截断
  并在界面标记。
- `jev_live` 暂不可用；需要 P4 Worker 代理、内存 Key、预算与取消。
- 单次运行对比没有 30 种子配对波动区间，界面只显示“描述性差异”，不得据此声称
  结构显著改变。
- 浏览器界面不是校准证据；结构结论以 `docs/07` 的预注册与统计验收为准。
